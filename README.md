# Random Colors

A tiny offline PWA for the iPad. It shows random full-screen colors from a set of distinct colors, changing at a fixed interval.

- **Setup:** choose the number of colors (2–12, taken in order from a list of very distinct colors) and the interval (0.25 s – 60 s). Your last settings are remembered.
- **Running:** the same color is never shown twice in a row. Tap the screen to pause, then choose **Resume** or **Settings**.

No build step and no dependencies: just static files.

## Run locally (Mac)

```sh
python3 -m http.server 8000
```
Open http://localhost:8000.

## Deploy to GitHub Pages and install on the iPad

1. Create a GitHub repo and push this folder to it.
2. In the repo, go to **Settings → Pages → Build and deployment**, set Source to *Deploy from a branch*, then pick `main` / `/ (root)`.
3. On the iPad, open `https://<user>.github.io/<repo>/` in Safari, then tap **Share → Add to Home Screen**.
4. Open it from the Home Screen. From then on it runs offline in full screen.

## Updating

After you change any file, bump `CACHE` in `sw.js` (e.g. `random-colors-v2`) and push. To pick up the new version, open the app once while online, then close it and open it again.

Icons are generated by `python3 tools/make-icons.py icons`.
